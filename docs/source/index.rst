3D-BrAIn
========

3D-BrAIn provides Python tools for 3Brain MEA recordings, including BRW/BXR file access, signal filtering, spike and burst analysis, spike sorting, clustering, merging-tree visualization, and neural signal synthesis experiments with PyTorch.

The project is organized as a source-layout package under ``src/brain_3d``. Most workflows use one or two focused modules rather than importing the whole package.
