# Portal data provenance

The 3D-BrAIn portal is a presentation layer. Scientific values, model metadata,
connectivity tables, and connectivity images must be generated by this
repository before they are copied into the portal build.

## Published data products

| Portal product | Authoritative generator | Authoritative output |
| --- | --- | --- |
| Spike and burst CSV | `main/main_compute_spike_burst_metrics.py` | `metrics/all_recordings_spike_burst_summary.csv` and per-recording metric CSV files |
| Connectivity CSV files | `main/main_run_negative_spike_connectivity_analysis.py` | `connectvity_neg/<recording>/*.csv` |
| STTC and correlation heatmaps | `main/main_run_negative_spike_connectivity_analysis.py` using `brain_3d.Connectivity.PlotConnectivityMatrix` | `connectvity_neg/<recording>/network_maps/*.png` |
| Activity and waveform features | `main/main_run_negative_spike_div_regression_analysis.py` | `recording_metadata_and_activity_features.csv` |
| Predictive model metadata and artifacts | classification and DIV-regression training pipelines | `final_models/portal_model_catalog.json` and matching `.joblib`/`.pt` artifacts |

The portal-side catalogue builder may split tables into one file per recording,
rename copies for stable URLs, and create JSON presentation records. It must not
calculate scientific features, metrics, or figures.

## Rebuild connectivity maps from existing results

For a normal new analysis, maps are written automatically inside each
recording's `network_maps` directory. To rebuild maps without recomputing
connectivity, run:

```bash
python3 main/main_run_negative_spike_connectivity_analysis.py \
  --output-root outputs/analisi_dati_Mark/experiment_4/connectvity_neg \
  --maps-only
```

If legacy result directories are read-only, use a separate reproducible output
directory:

```bash
python3 main/main_run_negative_spike_connectivity_analysis.py \
  --output-root outputs/analisi_dati_Mark/experiment_8/connectvity_neg \
  --maps-only \
  --maps-output-root outputs/analisi_dati_Mark/experiment_8/connectvity_neg/portal_maps
```

Both STTC and spike-count correlation heatmaps use the fixed range `[-1, 1]`,
so images are comparable across recordings.
